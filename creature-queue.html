Add work or control the worker

Run from PowerShell in the local project checkout. Add more clips while the worker runs; matching completed jobs reuse verified media.

.\tools\creature_workflow.ps1 queue clips --species Labraduck
.\tools\creature_workflow.ps1 queue add --species Labraduck --clip Walk --speed 3 --start
.\tools\creature_workflow.ps1 queue status
.\tools\creature_workflow.ps1 queue stop

Stop finishes the active job before exiting. Use queue cancel JOB_ID to cancel a specific job, or queue retry JOB_ID for an explicit retry.
