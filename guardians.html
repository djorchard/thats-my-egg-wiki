How guardian speed works

Chase is the configured movement speed while pursuing an egg thief. The shared chase delay is 1.2 seconds. The five main-route biomes through Jungle get progressively faster. Branch areas still use the default and need individual tuning.

Patrol / recovery applies while patrolling, approaching a dropped egg or returning home without an egg. A guard standing still or sleeping is not moving at that speed.

Egg return is patrol speed multiplied by 2.5, only while carrying an egg back to a nest. It does not multiply chase speed. A guardian carries at most one egg; if it catches a second thief while full, that thief's egg drops only when supported ground is available.

These values are movement targets. Obstacles, turns, pauses, jumps and route choice can change actual travel time. Chase, carry and multiplayer acceptance remains To do until tested.

Compare with player training

Normal empty-handed player speed is 16 + 8 * ln(1 + SpeedPoints / 100) studs per second, before developer multipliers. SpeedPoints are the saved training stat.

Carrying an egg multiplies that speed by max(0.55, 1 / (1 + eggKg * 0.06)). Heavier eggs need more training for the same escape speed.

At normal movement settings, approximate minimum whole SpeedPoints to match each starting guardian on an unobstructed path while empty-handed:

  • Sunnyside Backyard: 21 SpeedPoints to match 17.5 studs per second.
  • Clover Farm: 112 SpeedPoints to match 22 studs per second.
  • Ripplewater Lake: 250 SpeedPoints to match 26 studs per second.
  • Acorn Woods: 476 SpeedPoints to match 30 studs per second.
  • Jungle Wilds: 849 SpeedPoints to match 34 studs per second.

Matching speed does not guarantee escape, especially with an egg. When tuning, compare the intended player training level and egg weight against the chase value, then test the actual route.
