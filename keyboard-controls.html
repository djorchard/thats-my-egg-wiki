    Keyboard controls

    Assigned keys, context-specific controls and space for future shortcuts.

    Unassigned letter candidates: J, K, Y, Z. No project binding found is not a guarantee that a key is safe in every Roblox or operating-system context.

    Colour key

    Game controlContext / shared keyDeveloper / adminRoblox / systemNo project binding
    • J, K, Y and Z have no direct project action binding in this audit.
    • Grey keys mean no project binding was found, not a guarantee that Roblox, the operating system, typing or keyboard firmware leaves them unused.
    • The diagram uses a US ANSI layout. KeyCode refers to physical key positions; printed legends can differ on other keyboard layouts.
    • When a text field is focused, ordinary letter shortcuts normally yield to typing. House placement suppresses unrelated shortcuts, including otherwise unassigned letters.
    • This map records current source, not earlier chat intentions. R currently consumes food as well as praising pets; F is the drop/follow/gym-exit family.
    • Numpad keys have no explicit project binding. With Num Lock off, their navigation behavior depends on the keyboard and client.

    How this is kept accurate

    The builder scans mapped Luau sources for literal keyboard references, and verifies the source anchors for the listed actions. It refuses unknown key references rather than silently calling a new binding spare. Native defaults are checked separately. Dynamic input suppression and text entry do not constitute a dedicated action for every letter. This source audit does not establish live shortcut or input-priority acceptance.
