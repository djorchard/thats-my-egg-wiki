Search field with clear action

A reusable search component. Empty text hides the X; nonempty text shows it. Closing the owning screen clears its query.

Usage instructions

  1. Create a native TextBox with placeholder Search in Theme.Colors.placeholder (#9298A3), entered text in Theme.Colors.text, theme row surface, BuilderSans at 14, control radius 8 and height 44. Preserve established compact 32 or 36-pixel layouts.
  2. Decorate with InputFields.decorate. Reserve a 38-pixel leading gutter for the canonical 22-pixel search icon and 44 pixels for the trailing clear action.
  3. Call InputFields.search(field, owningWindow, existingClearButton). Omit the third argument to create the shared borderless X; supply it to reuse an existing clear control.
  4. Bind after the field and window are parented to their ScreenGui. The owner must be the screen window, not its tab or results container.
  5. Filter results with the field Text property signal. Clearing must restore the normal list without changing the selected tab or issuing a transaction.
  6. Closing the owning window or disabling its ScreenGui clears text and releases focus without submitting. Never focus the field automatically.

Selected item tile

The chosen item has a 3-pixel blue outline inside its existing corners. This native shared-constructor example uses three sample pets and the Garden, Stored and Collection tabs.

Usage instructions

  1. Use InventoryGrid.New for item lists and pass the current stable item ID, or the existing selected-ID set, to SetItems. Recycled tiles retain the owning feature selection.
  2. Custom selectable tiles call Grid.SetTileSelected(tile, Theme, selected). The owning feature chooses selection, handles input and reconciles server results; the helper only presents that choice.
  3. Use Theme.Colors.accent (#335FFF) for the 3-pixel UIStroke. BorderStrokePosition is Inner and StrokeSizingMode is FixedSize. Copy the actual four tile corner radii, including Collection square bottom corners.
  4. Keep the transparent outline passive above artwork and hover feedback. Preserve tile size, hit area, captions, counts, scrolling, dragging, keyboard focus and existing equipped or enabled fills.
  5. Available tiles have no blue outline. Selecting a different item moves it immediately; multi-select outlines every selected item within the existing feature limit. Unavailable and undiscovered items keep their availability rules.
  6. Pending selections retain their local feedback without confirming ownership, spending or grants. Hotbar drop destinations use a separate highlight. Tabs keep their selected underline.
  7. See UI_TILES.md for the state table, reusable code example and main-window cleanup rules. This constructor sample establishes appearance only; it is not a full Pets live UI or window-lifecycle test.

Quality chip

Compact saturated quality face, bright bevel and centred raised lettering.

Usage instructions

  1. Use Theme.DetailSkins for individual pet detail quality chips. Keep the existing egg and garden-pet callout treatments unchanged.
